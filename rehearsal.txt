#             so do not skip it.

#             should switch to the announcement block and the

#             room, with no one pressing anything.
#  start + 12 SET  washroom-override: off  and save. Every
#             washroom key goes red even though the time window
#             is open. Then CLEAR it again and watch them all
#             go back to green.
#  start + 15 BREAK something on purpose: change hours: 12 to
#             hours: twelve and save. Every toolbar should show
#             an orange warning naming the line. Fix it again.
#  start + 20 The hand-in key turns green by itself.
#  start + 28 The hand-in key turns red again by itself.
#  start + 30 Every screen turns red with the end message. Now
#             ask ONE person to press "Papers collected" on
#             their own machine. Only their screen turns green.
#             Everybody else should still be red. Then a second
#             person presses it.
#  start + 32 EXTEND the exam: change end: to start + 42 and
#             save. The boards that had ended go back to the
#             clock and the announcement, and the "Papers
#             collected" button disappears again.
#  start + 42 The real end. Everyone presses "Papers collected".
#  afterwards Leave every page open and untouched for 10 more
#             minutes. Nothing should blank, freeze or drift,
#             and the clocks should still agree at the end.
