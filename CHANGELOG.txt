EXAM BOARD CHANGELOG
Newest first. Version numbers are in the <title> and header comment of
each .html file and at the top of README.txt.

v1.0, 2026-11-09
  First release. The control file format is now settled: every setting
  added since v0.9 has a default that keeps the old behaviour, so a
  control file written for v0.9 still works unchanged.
  Used in a real exam (stand-alone version, two rooms) on 2026-11-09.

  Since v0.9:
  - date: and an idle screen, so the page can stay on a wall between
    exams and show "No exam in progress."
  - hours:, seconds:, times: and keys: to choose what the bottom half
    shows: 12- or 24-hour clock, seconds, the Start/End line, and
    which of the two keys appear (or none at all).
  - Pictures in announcements with \includegraphics.
  - The stand-alone version can read announcements from a control file
    on a server, with the address typed in its gear menu or carried in
    the link as ?src=, while its clock and keys stay controlled in the
    room. KaTeX is loaded from beside the control file.
  - Both pages keep the display awake while they are visible.
  - The clock is drawn in pure white on dark and near-black on light,
    so it is readable on a projector in either theme.
  - Fixed: a long announcement containing a picture could be cut off
    at the bottom of the panel. Text now shrinks to a readable floor
    and then the picture shrinks, so all of it fits.
  - Fixed: making the clock brighter had made its digits invisible in
    the light theme.

v1.0.1, 2026-11-09
  - layout: line (and a chooser in the stand-alone's gear menu) to put
    the clock and keys above the announcements instead of below.
  - The stand-alone's keys are named by position in the gear menu, "Top
    key" and "Bottom key", since their labels can be changed.
  - "Reset everything to defaults" in the stand-alone's gear menu, for
    a podium PC where the previous proctor's settings and message are
    still on screen. It removes only this page's own saved settings.

v0.9 (beta), 2026-10-15
  First version shown to colleagues.
  - Stand-alone exam-board.html: large clock, free-text announcements
    with adjustable size, Washroom and Hand-in keys (Allowed / Not
    allowed), undo, light/dark theme, settings in a gear menu.
  - Live exam-live.html: driven by exam.txt on the server; instructions
    before the start time with "Don't start yet, read above", then
    announcements and the clock; LaTeX with bundled KaTeX; keys turn
    green automatically inside their time windows, with manual
    overrides; optional countdown display (clock recommended).
  - Time taken from the hosting server's clock; optional external time
    server.
  - Logo slot and department name (default: Cheriton School of
    Computer Science).
  - End-of-exam message in place of the clock, and a per-room "Papers
    collected" switch that shows the release message.
  - Validation of exam.txt with warnings in the toolbar.
  - demo.txt, a sample control file for demonstrations.
  - Both pages keep the display awake while visible (screen wake lock).
  - Stand-alone can optionally read the announcements from a control
    file on a server (address in the gear menu), with KaTeX loaded from
    beside it, while the clock and keys stay controlled in the room.
    ?src= in the link sets that address, so one link can be sent to
    every room instead of each proctor typing it.
  - Pictures in announcements with \includegraphics (PNG, JPG, SVG, ...).
  - date: line and idle screen ("No exam in progress.") outside the exam.
  - seconds: line to show the clock as HH:MM instead of HH:MM:SS.
  - times: line to hide the "Start ... End ..." line under the clock.
  - hours: line to choose a 12- or 24-hour clock.
  - keys: line (and a chooser in the stand-alone's gear menu) to show
    both keys, one of them, or none, for rooms that want only the time
    and the announcements.
  - Fixed: a long announcement with a picture could be cut off at the
    bottom of the panel in the live version. Text now shrinks to a
    readable floor and then the picture shrinks, so all of it fits.
  - Clock drawn in pure white on dark and near-black on light, so it
    stays readable in both themes on a projector.
  - README with setup, checklist, customisation for other
    institutions, and beta/responsibility notice. MIT License.
